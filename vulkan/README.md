# Portal Red Vulkan

Página de acceso para la red Wi-Fi **Vulkan**: ingreso con ticket o cédula, términos y condiciones del servicio y planes (Básico 15 Mbps y Premium Pro 50 Mbps).

Es un solo archivo, [`index.html`](./index.html), con el estilo incluido. Ábrelo directamente en el navegador o súbelo a cualquier hosting estático (GitHub Pages, Netlify) o al portal cautivo de tu router.

Antes estaba guardada como texto dentro del cuaderno `Copia de vulkan.ipynb`.
